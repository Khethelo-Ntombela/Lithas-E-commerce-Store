**Litha's Store**
A lightweight, robust e-commerce platform designed to streamline online retail operations, product management, and customer transactions.

**Features:**
Product Management: Dynamic catalog browsing with detailed product views, categorization, and real-time inventory tracking.

Shopping Cart & Checkout: Secure, intuitive user workflow from item selection to order finalization.

User Authentication: Secure registration, login, and session management for customers and administrators.

Responsive Design: Fully optimized interface that provides a seamless experience across desktop, tablet, and mobile devices.

**Tech Stack:**
Frontend: HTML5, CSS3, JavaScript

Backend: PHP

Database: MySQL
